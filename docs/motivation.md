I want to create simple fast and easy to manage self hosted project tracking and note taking app.
Simple UI, fast and free. Why? Jira ends subscription, Clickup too slow and have too many features and complex ui, Notion also slow, Trello very limited, require additional subscription.

Also this application used to learn new programming approaches, patterns, techniques and so on. So 
many thing here might have not obvious solution because of I wanted to try something.

So this is my attempt.

### Core features:
- tasks
- sprints
- assignment
- role management
- simple api

### Not core features:
- reactions
- github/gitlab integration
- comments
- planer ( calendar - different views )
- webhooks
